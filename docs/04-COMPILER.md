# 4. Компилятор (дополнительно)

Перевод программ CIAO в исполняемый Python-код.

## Назначение

Альтернативный путь исполнения: исходный текст .ciao разбирается регулярными выражениями и превращается в готовый Python-код. Не использует сканер и AST из основной цепочки. Код генерируется в файл и выполняется через `exec()`.

## Компоненты

- **`compiler/main.py`** — класс `Ciao3Translator`, функция `main_translator()`
- Вход: `compiler/input.ciao`
- Выход: `compiler/output.py`

## Этапы

1. Парсинг текста: извлечение `class` и `scheme` через regex
2. Генерация Python: классы с автоматами в виде словарей, `ResettableTimer` для `after`, функции `main()` и `run()`
3. Запись в `output.py` и выполнение

## Вызов

```bash
cd compiler
python main.py
```

## Результат

Файл `output.py` с исполняемым кодом и его запуск.

## Особенности

- Не использует общий pipeline (scanner, build_ast, interpretator)
- Парсер на regex; может не покрывать все конструкции основного интерпретатора
