# 3. Интерпретация

Пошаговое выполнение: пользователь вводит команды вида `объект.событие`, программа меняет состояния автоматов.

## Назначение

Исполнение программы на CIAO в интерактивном режиме. Из AST строятся таблицы состояний и связей, создаются объекты. Пользователь вводит события (`human.pressSwitch`, `bulb.turnOff` и т.п.), интерпретатор обрабатывает переходы, выполняет эффекты, проверяет условия и поддерживает таймеры `after`.

## Компоненты

- **`interpretator/interpreter.py`** — класс `Interpreter`, функция `InterpretCode(ast)`
- **`interpretator/createTable.py`** — `GetTable()`, извлечение классов, scheme, objects, links из AST
- **`reservFunc/after.py`** — `TimerManager` для отложенных переходов `after(t)`

## Этапы

1. Построение таблиц: классы (events, effects, conditions, variables, assertions, states), scheme (objects, links, public, private)
2. Создание объектов и проверка связей
3. Цикл ввода: приглашение `>>>`, ожидание команд
4. Обработка команд: встроенные (`help`, `interfaces`, `exitCode`) или `объект.событие`
5. При `объект.событие`: поиск перехода в таблице состояний, проверка условий, смена состояния, выполнение эффектов (в т.ч. по связям), запуск таймера при `after`

## Вызов

Запускается после успешной загрузки файла и построения AST в `InterpretCode(ast)`.

## Результат

Интерактивное выполнение: вывод переходов и эффектов в консоль, изменение состояний объектов.
