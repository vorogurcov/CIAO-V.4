# 2. Построение AST

Синтаксический анализ и построение абстрактного синтаксического дерева.

## Назначение

Парсинг токенов по грамматике CIAO. Результат — AST (абстрактное синтаксическое дерево), структурное представление программы, согласованное с описанием внутреннего представления в статье по языку. Дальнейший runtime (очередь событий, интерпретатор) вынесен в `legacy/` и подлежит реализации с нуля по статье.

## Компоненты

- **`build_ast.py`** — `GetAST()`, координация: сканирование → парсинг → визуализация
- **`syntax/`** — парсер: `BuildAst()`, загрузка грамматики
- **`syntax/virt.py`** — чтение грамматики из `ciao_gv/*.gv` (формат Virt/Graphviz)
- **`syntax/build_ast.py`** — рекурсивный разбор по правилам

## Этапы

1. Загрузка описания грамматики из `ciao.json` и `ciao_gv/`
2. Вызов `Tokenize()` и `Afterscan()`
3. Построение дерева от аксиомы (`CIAO_PROGRAM`) вниз по правилам
4. При наличии `debugInfoDir` — генерация SVG-диаграммы AST в `_debug/`

## Вызов

Выполняется при вводе пути к .ciao файлу в `ciao.py` → `GetAST(jsonFile, codeFile, is_render)`.

## Результат

- `TreeNode` — корень AST
- Опционально: SVG-файл в `_debug/` с визуализацией дерева
