# 1. Сканирование

Разбор исходного кода на токены.

## Назначение

Лексический анализ: преобразование текста программы CIAO в последовательность токенов — атомарных единиц (идентификаторы, числа, ключевые слова, операторы). Это первый шаг в цепочке обработки.

## Компоненты

- **`scanner.py`** — функция `Tokenize(code)`  
- **`dsl_info_ciao.py`** — правила распознавания: `tokenRegularExpressions`  
- **`afterscan/`** — постобработка: помечает ключевые слова (`class`, `scheme`, `events` и т.д.) как KEY, устанавливает атрибуты для `else`, `true`, `false`

## Этапы

1. **Tokenize** — обход текста, сопоставление с регулярными выражениями (`number`, `name`, `char_key`, `string`)
2. **Afterscan** — замена распознанных идентификаторов на ключевые слова и настройка атрибутов

## Вызов

Сканирование выполняется автоматически при загрузке файла в `build_ast.GetAST()`.

Отдельно (для отладки):
```bash
python scanner.py путь/к/файлу.ciao
```

## Результат

Список токенов, готовый для парсера (построения AST).
