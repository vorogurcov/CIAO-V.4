# Обзор функциональностей CIAO

Документация описывает основные блоки проекта в порядке их выполнения в цепочке обработки.

---

## Порядок функциональностей

1. **[Сканирование](01-SCANNING.md)** — разбор исходного кода на токены  
2. **[Построение AST](02-BUILDING-AST.md)** — синтаксический анализ и абстрактное синтаксическое дерево  
3. **[Интерпретация](03-INTERPRETATION.md)** — пошаговое выполнение: пользователь вводит команды вида `объект.событие`, программа меняет состояния автоматов  
4. **[Компилятор](04-COMPILER.md)** *(дополнительно)* — перевод программ CIAO в исполняемый Python-код  

---

## Что делает проект

CIAO — предметно-ориентированный язык (DSL) для описания систем взаимодействующих конечных автоматов. Проект реализует:

- **Цепочку обработки**: исходный текст → токены → AST → выполнение
- **Интерактивный режим**: пользователь задаёт события объектам, система меняет состояния и выполняет эффекты
- **Альтернативный путь**: компиляция .ciao в Python без использования AST
