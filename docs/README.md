# Обзор: цепочка разбора CIAO (костяк)

Документация описывает блоки проекта в порядке выполнения для **построения AST** по грамматике языка (как в материале статьи `ImplementationOfCIAO` на уровне разбора программы).

---

## Порядок

1. **[Сканирование](01-SCANNING.md)** — разбор исходного кода на токены  
2. **[Построение AST](02-BUILDING-AST.md)** — синтаксический анализ и абстрактное синтаксическое дерево  

Интерпретация и компилятор в Python перенесены в **`legacy/docs/`** — они не входят в целевой костяк под очередную модель из статьи.

---

## Что делает проект (текущий костяк)

- **Цепочка**: исходный текст → токены → AST  
- **Точка входа**: `python ciao.py` — указать путь к `.ciao`, проверить успешное построение AST  

Старый интерактивный интерпретатор: `python legacy/run_interpreter.py` (см. `legacy/README.md`).
