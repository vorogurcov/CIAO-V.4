# CIAO — язык описания систем взаимодействующих автоматов

**CIAO** — предметно-ориентированный язык (DSL) для описания систем из взаимодействующих конечных автоматов. Программа на CIAO задаёт классы автоматов (события, эффекты, условия, переменные, переходы) и схему их связывания (объекты, связи, интерфейсы).

## Что делает проект

1. **Сканирование** — разбор исходного кода на токены  
2. **Построение AST** — синтаксический анализ и абстрактное синтаксическое дерево  
3. **Интерпретация** — пошаговое выполнение: пользователь вводит команды вида `объект.событие`, программа меняет состояния автоматов

Дополнительно: **компилятор** (`compiler/`) переводит программы CIAO в исполняемый Python-код.

## Запуск

### Основной режим (интерпретатор)

```bash
python ciao.py
```

После запуска:

1. Введите путь к файлу с программой (например, `TestPrograms/LightSwitch.ciao`)
2. Программа загрузится и начнётся интерактивный режим
3. Вводите команды вида `объект.событие` (например, `human.pressSwitch`)
4. Команды: `help` — справка, `interfaces` — доступные события, `exit` — выход из программы, `exitCode` — завершение текущей программы

### Компилятор (CIAO → Python)

```bash
cd compiler
python main.py
```

Читает `compiler/input.ciao`, создаёт `compiler/output.py` и запускает сгенерированный код.

| Компонент | Описание |
|-----------|----------|

| `build_ast.py` | Сборка AST из токенов |

| `ciao.json` | Конфигурация (синтаксис, директория отладки) |
| `ciao_gv/` | Диаграммы грамматики (Virt) |
| `TestPrograms/` | Примеры программ |

## Формат программы CIAO

```ciao
ciao ИмяПроекта
    class ИмяКласса
        events
            событие1
            событие2(параметр: Тип)
        effects
            эффект1
        conditions
            условие1
        variables
            переменная : Тип
        assertions
            утверждение <- выражение
        states
            Состояние1 -> событие1 [условие] / эффект1 -> Состояние2
            Состояние1 -> событие2 [else] / эффект2 -> Состояние3
    scheme
        objects
            obj = new Класс (НачальноеСостояние)
        links
            obj1.эффект <- obj2.событие
            obj1.условие <- obj2.утверждение
        public
            obj.событие
```

## Конфигурация

`ciao.json`:

- `syntax` — описание грамматики (тип, пути к диаграммам)
- `debugInfoDir` — папка для SVG-диаграмм AST (опционально)
