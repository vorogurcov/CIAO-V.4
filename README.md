# CIAO — язык описания систем взаимодействующих автоматов

**CIAO** — предметно-ориентированный язык (DSL) для описания систем из взаимодействующих конечных автоматов.

## Костяк репозитория (согласован с материалом статьи `ImplementationOfCIAO`)

Цепочка **исходный текст → токены → (afterscan) → синтаксис → AST**, как в описании языка и внутреннего представления программы на уровне разбора:

1. **Сканирование** — `scanner.py`  
2. **Постобработка токенов** — `afterscan/`  
3. **Синтаксис и AST** — `syntax/`, `build_ast.py`, `R_ast.py`  
4. **Грамматика** — `ciao_gv/` (диаграммы Virt), конфигурация — `ciao.json`, `dsl_info_ciao.py`, `dsl_token.py`

Точка входа для проверки разбора:

```bash
python ciao.py
```

Введите путь к файлу `.ciao` — будет построен AST (при настройке `debugInfoDir` в `ciao.json` — SVG в каталог отладки).

## Требования

- Python 3.7+  
- Для SVG AST: `pip install graphviz` (и установленный Graphviz в PATH)

```bash
pip install graphviz pydot
```
