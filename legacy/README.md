# Legacy: реализация, не совпадающая с очередной моделью статьи

Сюда перенесены компоненты, которые **отходят** от описания в `ImplementationOfCIAO` (рекурсивный интерпретатор вместо очереди событий, компилятор в Python, таймеры в отдельном потоке и т.д.). Их можно выбросить или переписать с нуля по статье.

## Содержимое

| Путь | Назначение |
|------|------------|
| `interpretator/` | Интерпретатор (таблицы состояний, рекурсивные вызовы по links) |
| `compiler/` | Компилятор CIAO → Python |
| `reservFunc/` | `after` (таймер в отдельном потоке) |
| `TestPrograms/` | Примеры под старый интерпретатор |
| `Examples/` | Сгенерированные диаграммы AST для примеров |
| `interpreterBootstrap.py` | Обвязка под сгенерированный код |
| `automatonInfo.py` | Доступ к таблице интерпретатора из bootstrap |
| `docs/` | Старые отчёты, ТЗ на параллельный runtime, интерпретация/компилятор в документации |

## Запуск старого интерактивного интерпретатора

Из корня репозитория:

```bash
python legacy/run_interpreter.py
```

Скрипт добавляет `legacy/` в `sys.path`, чтобы работали импорты `interpretator` и `reservFunc`.

## Запуск компилятора в Python

```bash
cd legacy/compiler
python main.py
```
